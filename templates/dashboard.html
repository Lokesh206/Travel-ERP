ENGINEERING SPECIFICATION

3. System Architecture & Commission Calculation Logic

4-TIER HIERARCHICAL REVENUE ENGINE

A. System Architecture Layers

🖥️

1. Presentation Layer (Jinja2 & Modern CSS)

Server-rendered responsive UI with DM Sans & Manrope typography, glassmorphism, dynamic table filtering, and auto-scrolling landmark photo marquee.

⚙️

2. Application & Security Layer (Flask & Python)

Stateless HTTP routing, cryptographically secure CSRF tokens on all POST requests, role-based access control decorators (@roles_required), and scrypt password hashing.

🗄️

3. Persistence & Ledger Layer (SQLite3 WAL)

ACID-compliant relational database with foreign key constraints, recursive CTE queries for downline trees, and an immutable double-entry wallet ledger for commission credits and withdrawal debits.

B. Commission Calculation Logic

When a journey status transitions to Completed, the system executes a recursive 4-level commission settlement algorithm traversing the upline referral hierarchy:

TIER LEVEL AGENT POSITION RATE (BPS) PERCENTAGE
Level 1 Direct Booking Agent 500 bps 5.0%
Level 2 Direct Parent / L1 Upline 200 bps 2.0%
Level 3 Senior Partner / L2 Upline 100 bps 1.0%
Level 4 Apex Principal / L3 Upline 50 bps 0.5%
Platform Wanderwise Gross Retained Margin 9,150 bps 91.5%

* Formula: Commission (₹) = (Booking Amount in Paise × Rate BPS // 10000) / 100
